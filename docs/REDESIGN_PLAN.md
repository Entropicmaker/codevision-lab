# CodeVision Lab 跨端视觉改造计划

> **已完成的历史实施计划（2026-08）**：用于说明本轮视觉与响应式改造的目标和验收口径。
> 后续 UI 工作以 `AGENTS.md`、`ENGINEERING_WORKFLOW.md` 与 `QUALITY_CHECKLIST.md` 为准。

## 目标

- 与个人博客保持同一作者气质：米白纸色、深海墨色、苔绿、沙棕与宋体标题。
- 用克制的电子青、坐标线、终端扫描纹理表达复古未来科技感。
- 用半透明材质、柔和阴影、大圆角和清晰动效表达 Apple 式交互质感。
- 手机、平板、小桌面和宽桌面均保持内容可读、操作可点、页面无横向溢出。

## 响应式策略

| 区间 | 布局原则 |
| --- | --- |
| 320–639px | 单列信息流；全宽主操作；44px 触控目标；三层播放控制器；折叠目录 |
| 640–1023px | 双列卡片；抽屉导航；较大的代码/图表工作区；折叠目录 |
| 1024–1279px | 平板/小桌面仍使用标签式算法实验室，避免三栏挤压 |
| 1280px 以上 | 完整导航；算法实验室三栏；固定目录与状态侧栏 |

## 改造范围

1. 重建全局设计令牌、页面背景、字体层级、玻璃材质与交互状态。
2. 重做首页首屏、功能卡、语言入口、算法索引和路线图入口。
3. 将顶部导航改为宽屏导航与手机/平板抽屉导航。
4. 重构算法实验室的断点、标签内容区、输入栏和底部播放控制器。
5. 统一课程、算法目录、数据结构、练习、路线图、实验室和进度页的页面语言。
6. 增加 1024 × 1366 平板测试，并验证手机与平板核心页面无横向溢出。

## 验收标准

- 320px 宽度下无页面级横向滚动。
- 手机和平板可完成导航、切换实验室标签、输入数据和播放算法。
- 1024px 宽度不显示拥挤的三栏实验室。
- 交互控件在触控设备上的最小高度为 44px。
- 深浅主题均保持足够对比度，并尊重“减少动态效果”系统设置。
- 类型检查、单元测试、生产构建和跨端 Playwright 测试全部通过。
