# LingeoCS 系列站点导航规范

## 品牌结构

- 母品牌：`LingeoCS`
- 主站：选择性失忆博客，`https://lingeocs.com/`
- 主站职责：作者身份、文章、项目总览与全部系列子站的汇总入口。
- 当前子站：CodeVision Lab，`https://lingeocs.com/codevision-lab/`

博客与子站不是平级关系：博客是主站，CodeVision Lab 与未来产品是系列子站。每个子站保留自己的产品名称、信息架构和视觉重心；`LingeoCS` 承担主站身份、站群归属和跨站导航。

## 固定接入点

每个系列站至少提供：

1. 顶部「LingeoCS 系列」切换器，显示主站与全部公开子站；
2. 移动端菜单中的等价入口；
3. 页脚文本链接，作为无脚本、无障碍和搜索引擎的稳定兜底；
4. 博客项目页中的子站介绍与入口。

切换器不能成为唯一入口。跨站链接默认在当前标签页打开，保持普通导航预期。

## 数据位置

- 博客主站：`src/data/ecosystem.ts`
- CodeVision Lab：`src/data/ecosystem.ts`

两个仓库独立构建，因此清单需要同步维护。字段语义保持一致：稳定 id、产品名、定位、简述、公开 URL、系列编号、是否主站。

## 新增子站清单

1. 确定稳定 id、名称、单句定位和正式 URL。
2. 将新站加入所有现有站点的 ecosystem 清单。
3. 新站接入顶部切换器、移动入口和页脚兜底。
4. 博客始终标记“主站”；子站提供“返回主站”，并明确标记当前站。
5. 检查 320px、390px、1024px 与桌面宽度，系列入口不能挤压主导航。
6. 检查键盘打开、Escape 关闭、点击外部关闭与可见焦点。
7. 检查深浅主题对比度。
8. 分别构建、部署，再从线上双向点击验证。

## 文案与视觉

- 中文统一称「LingeoCS 系列」；英文使用 `LingeoCS Network` 或 `LingeoCS Sites`。
- 使用现有深海、苔绿、沙棕和电子青语义色，不新增竞争性品牌色。
- 切换器是工具型组件，尺寸保持克制，不遮挡主任务。
- 当前站用文字和背景共同标识，不能只靠颜色。
