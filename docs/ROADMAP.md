# CodeVision Lab 路线图

> 本文件描述当前真实基线与后续优先级。数量与测试结果是 2026-08-16 的快照；后续代理完成内容后应同步更新。历史初版方案见 `DESIGN.md`，跨端改造记录见 `REDESIGN_PLAN.md`。

## 当前稳定基线

### 产品与体验

- 首页、路线图、算法库、算法实验室、数据结构、三语言课程、在线实验室、练习和进度页面均已上线。
- 手机、平板与桌面响应式布局已完成；支持深浅主题、中英文 UI、键盘焦点与减少动态效果。
- 视觉风格统一为博客深海自然色系、复古未来科技点缀与 Apple 式材质/层级。
- 进度、收藏和设置保存在 localStorage，可导入导出；当前没有账号或云同步。
- Python 在 Pyodide Worker 中真实执行；C++/C# 保持演示模式。

### 内容

- 27 个已注册算法：冒泡、选择、插入、快速、归并、堆排序、二分搜索、双指针、滑动窗口、栈、队列、链表、哈希表、二叉树遍历、DFS、BFS、拓扑排序、Dijkstra、Bellman-Ford、Floyd-Warshall、Prim、Kruskal、Fibonacci DP、0-1 背包、N 皇后、KMP、活动选择。
- 24 个已注册课程知识点，C++、C#、Python 各 8 个。
- 练习页直接使用每个课程知识点的 `exercise` 数据。
- 最近一次内容准确性评审记录位于 `docs/reviews/content-accuracy-2026-08.md`；新内容仍需独立复核。

### 工程质量

- TypeScript strict。
- 30 个单元测试文件、333 项单元测试通过（2026-08-16 基线）。
- Playwright 覆盖桌面、手机与 1024px 平板；生产 smoke 会在线执行真实 Python。
- push 到 `main` 自动执行 build → GitHub Pages deploy → production-smoke。

## 下一阶段优先级

### P0：让内容扩展可持续

目标：DeepSeek 批量补知识点时，错误能在合并前被自动发现。

- [ ] 为课程注册表增加不变量测试：id 唯一、章节存在、先修存在、代码示例齐全、练习字段完整。
- [ ] 为课程先修关系增加环检测和排序校验。
- [ ] 建立课程代码片段的可执行/可编译验证策略；优先自动 AST 检查 Python，逐步补 C++/C# 编译检查。
- [ ] 为内容增加可选的事实来源/审核状态元数据，避免模型生成内容无法追溯。
- [ ] 完成课程双语 schema 设计：`concept`、`hints`、`answer` 的兼容迁移、页面渲染与测试。
- [ ] 把内容批次控制在 3–5 课，并按 `CONTENT_AUTHORING.md` 留下评审记录。

完成定义：新增一课时，注册/先修/字段缺失能被测试阻止；中英文内容不依赖页面里的临时隐藏逻辑。

### P1：补齐三语言基础课程

按“先基础、后高级；先形成连续学习路径、再追求总量”推进。

#### C++ 基础批次

- [ ] 作用域与命名空间
- [ ] 数组与多维数组
- [ ] `std::string`
- [ ] 结构体与枚举
- [ ] 引用、动态内存、栈与堆（在现有指针课后）

#### C# 基础批次

- [ ] 方法与参数
- [ ] 枚举
- [ ] 值类型与引用类型
- [ ] 类、对象与属性
- [ ] 接口、泛型和异常基础

#### Python 基础批次

- [ ] 参数形式：位置、关键字、默认、`*args/**kwargs`
- [ ] 模块与包
- [ ] 文件读写与上下文管理器
- [ ] 异常处理
- [ ] 类与对象、迭代器

每一课必须同时带三语言对比、常见错误、递进提示和可运行答案，并能从课程树、练习页和进度页访问。

### P2：练习系统数据化

- [ ] 将练习从 `LessonMeta` 的单题扩展为独立 Exercise schema 与 registry。
- [ ] 支持题目类型、知识点标签、难度、测试用例、多个提示、参考解与替代解。
- [ ] 区分“看完课程”“提交过练习”“通过练习”，设计兼容的本地进度迁移。
- [ ] 先为 Python 提供安全的浏览器内测试用例执行。
- [ ] 增加错题/重练筛选与本地导入导出。

自动判题不等于安全执行。C++/C# 真实判题必须等后端沙箱方案独立评审后再做。

### P3：算法与数据结构扩展

- [ ] 排序：希尔、计数、基数。
- [ ] 高级结构：堆操作专题、Trie、并查集。
- [ ] 动态规划：LCS、LIS、编辑距离、区间 DP 入门。
- [ ] 图：A* 入门、强连通分量、关键路径。
- [ ] 回溯/贪心：排列组合、子集、迷宫、区间调度变体。
- [ ] 字符串/数学：Rabin-Karp、前缀函数、筛法、GCD。
- [ ] 案例导出/导入 JSON，并提供 schema 校验。

新增算法严格遵守 `ALGORITHM_CONTRIBUTING.md`，优先补足现有渲染器能表达的算法，不为单个内容复制整套页面。

### P4：高级课程可视化

- [ ] C++：对象生命周期、RAII、智能指针、移动语义。
- [ ] C#：委托/事件、LINQ 延迟执行、async/await 与 Task。
- [ ] Python：生成器、装饰器、闭包、协程、引用与 GC。
- [ ] 建立内存图/流程图通用 schema，课程演示继续复用 Step 与 PlaybackController。

### P5：需要单独产品决策的能力

以下项目不应由代理在普通内容任务中自行启动：

- C++/C# 后端 Docker 沙箱与真实编译；
- 用户账号、数据库与云同步；
- 多设备同步、社交或排行榜；
- 遥测、分析、付费服务；
- 大规模内容 CMS。

它们涉及成本、安全、隐私和运维，必须先有用户明确授权、威胁模型和独立实施计划。

## 每个里程碑的共同完成标准

- 功能与文案没有夸大现有能力。
- 内容事实经过验证，示例输出与答案正确。
- TypeScript、单元测试、生产构建通过。
- 相关 Playwright 与真实浏览器跨端检查通过。
- 中英文、深浅主题、键盘和减少动态效果无回归。
- 文档、计数、测试记录和路线图同步更新。
- 若用户要求上传：commit、push、Actions、生产 smoke 全部完成。
